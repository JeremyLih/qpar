\noindent This is the supplementary material for the paper ``Q-Par: A Resource-Aware Composite Metric for Comparing Hybrid CNN--QNN Models under NISQ Constraints.'' It contains the four tables referenced in the main text: Table~\ref{tab:rank_moves} lists the configurations whose rank moves by at least 10 places (Section~\ref{sec:res-rank}); Table~\ref{tab:sensitivity_supplement} repeats the sensitivity analysis with the qubit sweep included, where $Q$ varies (Section~\ref{sec:res-sens}); Table~\ref{tab:matched_stats} gives the paired tests of hybrid against matched models (Section~\ref{sec:res-base}); and Table~\ref{tab:full} is the full 54-configuration matrix of each dataset (Section~\ref{sec:res-rank}).

All tables are computed from the same run records as the article and can be regenerated from the code at \url{https://github.com/JeremyLih/qpar}.\EOD
